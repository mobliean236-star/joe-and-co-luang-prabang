## Website

Responsive single-page cafe website built with plain HTML and CSS.

- `index.html` — the complete website (styles and small script included)
- `.nojekyll` — tells GitHub Pages to serve the site as a static website

## Publish with GitHub Pages

1. Open this repository's **Settings** tab.
2. In the left menu, select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Set the branch to `main` and the folder to `/(root)`.
5. Click **Save**.

Once GitHub Pages finishes publishing, the site should be available at:

https://mobliean236-star.github.io/joe-and-co-luang-prabang/

## Before sharing the site

- Replace the sample address in the "Find our spot" section with the exact shop address or a Google Maps link.
- Replace the generic Instagram and Facebook links with the official Joe & Co. profiles.
- The website currently uses sample cafe and food photos hosted by Unsplash. Replace them with your own photos when ready.
- Check that the opening hours (9 AM–6 PM, every day) are correct.

## Visual direction

Warm cream, espresso brown, editorial serif typography, and a relaxed music-inspired cafe identity.
